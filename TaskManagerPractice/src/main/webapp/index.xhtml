Task Manager Practice

This practice project is used for DMIT2015 Lesson 7–10.

You will use this project to practice Strategy Pattern architecture, memory persistence, Firebase Realtime Database, Firebase Authentication, and multi-tenant user-scoped data.

Recommended Workflow

  1. Confirm the starter project runs.
  2. Implement and test the memory service.
  3. Switch to Firebase Realtime Database.
  4. Add Firebase Authentication.
  5. Convert to multi-tenant user-scoped data.
  6. Configure Firebase security rules.

Do not start directly with multi-tenant Firebase.

Use the navigation menu to access the practice pages as you create them.
